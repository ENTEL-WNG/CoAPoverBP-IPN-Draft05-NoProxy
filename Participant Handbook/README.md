# Participant Handbook

This folder contains the **IETF 127 CoAP over BPv7 Hackathon Participant Lab Manual**.

The manual provides step-by-step instructions for downloading the project repository, configuring the Rover, Satellite, and Earth virtual machines, installing the required software, establishing network connections, and running the CoAP-over-BPv7 experiments.

## Contents

- **IETF127_CoAP_over_BPv7_Participant_Lab_Manual.pdf** — Detailed instructions for setting up and testing the three-node DTN environment.
