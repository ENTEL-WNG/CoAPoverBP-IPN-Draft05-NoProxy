# Demo Videos — IETF 127 CoAP over BPv7

These are silent, English-subtitled demonstration videos used for the CoAP-over-BPv7 research testbed.

- `IETF127_Lua_Dissector_Tutorial/` — steps to install and validate the experimental Wireshark Lua dissector.
- `IETF127_Single_Bundle_Demo/` — single CoAP NON GET over BPv7 and Wireshark verification.

Each folder contains an `.mp4` video and a matching `.srt` subtitle file. The packet observations in these edited videos come from the demonstrated testbed, and individual screenshots may represent different runs.
